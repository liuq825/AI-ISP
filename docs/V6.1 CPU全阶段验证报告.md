## 4. ONNX 与制品审计

- Mixed ONNX：单一静态图；CPU 冒烟 Shape 为 `[1,4,32,48]`，发布目标仍为 `[1,4,768,1024]`；
- 输入类型：`packed_raw=FP16`、`condition=FP32`；
- 输出类型：`noise_pred=FP16`；
- Condition 直接 Cast：1；
- QuantizeLinear/DequantizeLinear：各 394；
- 非白名单算子：0；动态 Gate/Slice：0；
- 大体积 ONNX/权重仅在本地归档，Manifest 保存 SHA-256；
- 落选候选可执行目录和旧公共训练残留均已清理。
