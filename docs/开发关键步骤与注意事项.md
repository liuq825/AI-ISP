## 2. 必须长期遵守的注意事项

### 2.1 RAW 与 CFA

- 模型输入、`noise_pred` 和有效输出必须处于同一个 Packed RAW 格点；禁止对低分辨率残差插值后回写高分辨率 Bayer。
- Packed 通道唯一顺序是 R、Gr、Gb、B。所有旋转、镜像和 Crop 必须保持语义通道与 Bayer 相位。
- Bayer Crop 左上角必须为偶数坐标；奇数上游尺寸应由 HAL 拒绝或先执行相位安全的偶数 Crop。
- SIDD 的 CFA 映射来自 `datasets/SIDD_Blocks/bayer_patterns.csv`，不得按文件名之外的经验猜测。

### 2.2 SIDD 数据读取

- 完整 RAW 的 HDF5 数据集键固定检查为 `x`；读取后从 `[W,H]` 转为 `[H,W]`。
- 训练按 Patch 读取 HDF5，禁止把多张 12MP RAW 整体载入内存。
- 同一场景、Burst、连续拍摄片段只能进入一个划分。当前代码按 `scene_name` 划分；后续引入多帧时仍必须以 Scene/Burst 为组。
- 当前 SIDD 已归一化到 `[0,1]`，不能再套用未知 Black/White Level。目标设备数据必须使用版本化的四通道 Black/White 标定。
- `datasets/` 已加入 `.gitignore`，禁止把公开数据、目标设备 RAW、缩略图或可逆图像特征推送到 GitHub。

### 2.3 模型与强度

- Student 发布图只输出 `noise_pred`，最终结果为 `clamp(raw_in-noise_pred,0,1)`。
- `enhancement_strength` 在模型图内对输出噪声做一次缩放，确保强度 0 时位精确恒等；Runtime 图外不得再次缩放。
- StaticSimpleGate 的切点来自构造期常量。每次剪枝、升级 PyTorch 或更换导出器后，都要重跑 ONNX Slice 常量审计。
- RepDenseGate 只是端侧 A/B 候选；未经麒麟 9000 微基准、整网画质和功耗证据，不得替换 MobileNAFBlock-DW 基线。

### 2.4 CPU、ONNX 与 NPU 边界

- 本机 CPU 可以训练小 Patch 并导出真实发布 Shape ONNX，但 P0/P1/P2 推理约为 1.0～1.6 秒/帧，不满足 30fps。
- CPU 结果只证明工程链路和数值正确性，不能代替目标设备画质、OM、NPU 落点、时延、内存、功耗或热稳态结论。
- C++ Runtime 在 NPU 不可用时必须 Bypass 原始 RAW；禁止自动调用 PyTorch/ONNX Runtime 作为量产回退。
- 当前发布 ONNX 使用 legacy TorchScript exporter，以保证 Static Slice 审计稳定。迁移到 `torch.export` exporter 时必须重新验证算子、Hash 和数值等价。

### 2.5 量化与发布

- PTQ 当前只完成张量与 Q/DQ 前置验链，不是发布量化模型。
- LSQ+ 的非零 Activation Offset 必须先通过目标 DDK 两层微基准；不支持或破坏融合时冻结为对称 Offset=0。
- 发布必须保存 topology JSON、safetensors、Condition Schema、Sensor Profile、Quant Policy、ONNX/OM Hash 和工具版本。
- 当前 `model_manifest.json` 的 `release_ready=false` 是有意设置；只有目标设备 Go/No-Go 全部通过后才能修改。

## 3. 常用命令

```powershell
# 激活环境（可选）
.\.venv\Scripts\Activate.ps1

# 全部 Python 测试
.\.venv\Scripts\python.exe -m pytest -q

# 少量真实数据跑通训练、冻结、PTQ 和小 Shape ONNX
.\.venv\Scripts\python.exe -m ai_isp.cli `
  --dataset-root datasets\SIDD_Training_Subset `
  --output-dir artifacts\cpu_smoke `
  --steps 4 --patch-size 32 --max-pairs 2 --profile-mode smoke

# 发布 Shape CPU 基准
.\.venv\Scripts\python.exe .\tools\CPU发布分辨率基准.py --iterations 3

# 导出发布 Shape 时将 profile mode 改为 release；需要更高内存和时间
.\.venv\Scripts\python.exe -m ai_isp.cli `
  --dataset-root datasets\SIDD_Training_Subset `
  --output-dir artifacts\cpu_release `
  --steps 4 --patch-size 32 --max-pairs 2 --profile-mode release
```
