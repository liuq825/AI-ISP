# AI ISP V4 开发关键步骤与注意事项

> 更新日期：2026-08-05
> 当前阶段：算法与模型压缩 CPU 工程闭环通过，真实 RYYB/商用 DDK/麒麟 9000 发布验收待执行
> 原则：只记录会影响复现、画质、性能、安全或发布判断的事实。

## 1. V4 冻结决策

1. AI 只服务 RYYB 广角主摄与 RYYB 潜望式长焦，两者共用一套条件式 MobileNAFNet 权重和一个最终 OM。
2. RGGB 超广角不进入本模型，固定使用传统 ISP NR。该解耦消除了 CFA、画幅和多动态 Shape 对部署图的耦合。
3. 模型输入固定为 `packed_raw[1,4,768,1024]`，对应 `2048×1536`、4:3 RYYB，通道语义固定为 `[R,Yr,Yb,B]`；Condition 固定为 `float32[1,24]`。
4. 最终发布名称固定为 `dark_preview_ryyb_4x3_int8.om`。研发 A/B 可产生多个候选，但 Release 包只能复制通过验收的一个 OM。
5. AI 节点预算冻结为 P50≤6ms、P95≤8ms、P99≤9ms、10ms硬超时；这是 33.33ms 整条 4K30 Pipeline 的预算分配，必须由目标机实测确认。

## 2. 已完成的开发步骤

### 2.1 数据与接口

- 新增 RYYB 四相位 `ryyb/byyr/yryb/ybyr` Pack/Unpack，并统一输出 `[R,Yr,Yb,B]`。
- 新增 JSONL Manifest、Scene/Burst 防泄漏校验、相位安全 Patch、main/tele 平衡采样和真实 RYYB NPY 数据集。
- HAL 准入同时校验 Camera、Sensor、CFA、偶数 Crop、固定 Shape、Stride、位深、四通道 Black/White Level 及版本 Hash。
- 收紧 ConditionSchemaV2：发布态只允许 main/tele 对应的 Sensor/Lens 组合；ultrawide/other 必须为0。
- SIDD 每个 Batch 强制返回 `smoke_only=true`，不能进入 RYYB 模型选择和发布结论。

### 2.2 模型、训练与 KD

- 完成 W32 Conditional NAFNet Teacher 和 W16 Conditional MobileNAFNet Student 的真实前向、反向与特征接口。
- 监督损失实现 RAW/Tone/Gradient；KD 使用 Stage3、Middle 和最终输出，训练 Adapter 不进入发布图。
- Teacher 在 KD 中固定 `eval()`、`requires_grad=False` 和 `no_grad()`；Student 支持 CUDA AMP、GradScaler 与梯度累积。
- 统一阶段运行器支持固定随机种子、Warmup/Cosine LR、Checkpoint、阶段报告、断点续训、配置 Hash 和峰值显存记录。
- Checkpoint Hash 排除 `output_dir` 与 `resume_from`，允许在不改变训练数学配置的前提下迁移目录恢复。

### 2.3 结构化剪枝

- 使用 `torch-pruning==1.6.1` DependencyGraph 真正改变 Conv、DWConv、Gate、Skip、Down/Up、FiLM Head 和残差参数 Shape。
- 重要度实现 `0.5 Taylor + 0.3 Magnitude/Residual Scale + 0.2 Activation`。
- Stage1/Intro/Ending 不剪，其余以8通道为组，并执行候选副本预演，避免单次裁剪越过目标区间。
- 每轮刷新 StaticSimpleGate 属性并校验 2C 隐藏宽度、DWConv groups、拓扑冻结、safetensors 重载和可训练性。
- CPU 冒烟结果：P10 宽度 `[16,32,56,128]`，参数下降 9.234%；P15 宽度 `[16,32,56,120]`，参数下降 14.439%。

### 2.4 LSQ/LSQ+ QAT

- 权重：INT8 signed symmetric、Per-output-channel、Offset=0；激活：INT8 signed、Per-tensor。
- 补齐 STE、LSQ Gradient Scale、权重量化器、整网模块转换、Observer、Q0 校准、Q1/Q2/Q3、Q/DQ 导出和逐层审计。
- Q0 在 `99.9/99.95/99.99/100` Percentile 候选间，以黑位附近/暗部/中灰/高光分桶等权 MSE 选择。
- 4096 帧量产校准改为流式送入，只保留首批用于 Q3 冻结等价性检查，禁止整集常驻内存。
- P10 与 P15 都执行对称 LSQ 和非对称 LSQ+，形成四套完整候选；没有目标端 Offset 微基准时，工程导出保守选择 P10+对称 LSQ。
- FiLM 默认全 W8A8；只有画质触发且 FP16 Island 仍满足 100% NPU/P95≤8ms 时才允许选择。

### 2.5 ONNX、OM 与 Runtime

- `StaticSimpleGate` 使用构造期常量 `torch.narrow`。禁止全局 Monkey Patch；遗留外部模型只允许在副本上做受控模块替换。
- 单 Shape ONNX 审计禁止动态 Split/Chunk，要求 Slice 参数常量化、Gate 两半相等、PyTorch/ONNX 最大误差≤`1e-4`。
- QAT 导出显式 `QuantizeLinear/DequantizeLinear`，并输出 Quant Policy。
- OM 编译器只接受固定输入；找不到 ATC 时返回 `available=false`，不会生成假 OM。
- C++ Runtime 已改为固定 RYYB Profile、main/tele 准入和 ultrawide Bypass。工具虽不在 PATH，但已通过 Visual Studio 2022 的明确路径重新编译 V4，并由 CTest 验证 `1/1` 通过。

## 3. 必须长期遵守的规则

### 3.1 CFA 与 Crop

- Crop `x/y/width/height` 必须全部为偶数。奇数相位直接拒绝，禁止通道交换、补行、丢列或 Resize 补救。
- 每颗 Sensor 必须有独立相位表、Black/White Level 和噪声标定；不得按 Camera 名称猜测。
- 四通道 Pack 不减少 RAW 样本总数，也不应宣称天然降低 DMA 字节。

### 3.2 数据和画质

- 每颗 Camera 最低 Train/Validation/Blind 场景数为 3000/300/500；同一 Scene/Burst/连续片段只能属于一个划分。
- 训练 Patch 默认 256/384，显存允许时后期 512；全尺寸只用于导出、全帧验证和端侧测试。
- 仓库中的 RYYB 解混矩阵是工程占位值；真实光谱标定未完成前必须保持 `release_ready=false`。
- SIDD 只能验证代码链，禁止用于 RYYB 量产画质、Camera 选择或发布判断。

### 3.3 显存和训练

- 梯度累积改善有效 Batch，不降低单样本激活显存。
- 24GB GPU 先使用 Patch、Teacher no_grad、Student AMP；超过22GB软门槛后依次启用 Student 检查点、减小 Patch/增加累积、Teacher FP16特征缓存。
- 禁止捕获 OOM 后静默跳过 KD，禁止默认 CPU Offload 掩盖不可部署配置。

### 3.4 量化和性能

- 非零 Activation Offset 必须在长周期训练前完成目标 DDK 双 Block 微基准；编译/融合/NPU落点失败或P95回归超过 `min(3%,0.1ms)` 即固定 Offset=0。
- P10/P15、LSQ/LSQ+和FiLM精度最终选择必须同时满足真实RYYB画质、内存与麒麟9000时延，CPU Smoke 不能代替。
- 10ms超时直接走传统ISP；禁止CPU执行MobileNAFNet作为实时回退。

## 5. 发布前剩余硬门禁

1. 主摄/长焦真实RYYB数据规模、标定、无泄漏和盲测通过；
2. 量产配置的Teacher/Student/KD/P10/P15恢复及四套QAT候选收敛；
3. 目标商用DDK完成Offset前置微基准、Q/DQ适配、ATC和逐层审计；
4. 麒麟9000达到100% NPU、AI 6/8/9/10ms、整条4K30；
5. 10000帧、10/30分钟热稳态、内存、功耗、Camera切换和传统ISP回滚通过；
6. 最终发布目录只有一个OM，所有Schema/Profile/Topology/Quant/模型Hash一致。

任何一项缺失，`release_ready` 必须保持 `false`。
